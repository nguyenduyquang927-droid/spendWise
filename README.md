# SPENDWISE – WEBSITE QUẢN LÝ CHI TIÊU CÁ NHÂN

## 1. Tên đề tài
**SpendWise – Website quản lý chi tiêu cá nhân.**

## 2. Tên trang đã thực hiện
**Dashboard – Trang Tổng quan tài chính.**

## 3. Mục đích của trang
Trang Dashboard được xây dựng nhằm giúp người dùng theo dõi và quản lý tình hình tài chính cá nhân một cách trực quan, dễ dàng.

Trang cung cấp thông tin tổng quan về số dư hiện tại, thu nhập, chi tiêu, ngân sách và các mục tiêu tiết kiệm. Qua đó, người dùng có thể nắm bắt tình hình tài chính và kiểm soát việc chi tiêu hiệu quả hơn.

## 4. Các chức năng chính
- Hiển thị tổng quan số dư tài khoản.
- Hiển thị thông tin thu nhập và chi tiêu.
- Hiển thị biểu đồ chi tiêu trong 7 ngày.
- Hiển thị ngân sách theo từng danh mục.
- Hiển thị tiến độ mục tiêu tiết kiệm.
- Thanh điều hướng giữa các mục trong hệ thống.
- Xử lý một số thao tác tương tác bằng JavaScript.
- Hỗ trợ hiển thị giao diện trên các kích thước màn hình khác nhau (Responsive).

## 5. Công nghệ sử dụng

| Công nghệ | Mục đích |
|---|---|
| HTML | Xây dựng cấu trúc trang web. |
| CSS| Thiết kế giao diện, bố cục và Responsive. |
| JavaScript | Xử lý chức năng và tương tác người dùng. |
| Visual Studio Code | Môi trường viết mã nguồn. |
| Figma | Thiết kế giao diện trang web. |
| GitHub | Lưu trữ và quản lý mã nguồn. |

## 6. Cấu trúc thư mục

```text
SpendWise/
│
├── tongquan.html
├── tongquan.css
├── tongquan.js
└── README.md
```

## 7. Hướng dẫn chạy chương trình

1. Tải hoặc Clone dự án về máy tính.
2. Mở thư mục dự án bằng Visual Studio Code.
3. Mở file `tongquan.html` bằng trình duyệt hoặc sử dụng tiện ích Live Server.
4. Trải nghiệm giao diện Dashboard SpendWise.

## 8. Kết luận

Trang Dashboard của SpendWise giúp người dùng quản lý và theo dõi tài chính cá nhân thông qua giao diện trực quan, dễ sử dụng. Dự án được xây dựng bằng HTML, CSS và JavaScript nhằm vận dụng các kiến thức cơ bản về phát triển ứng dụng web.
